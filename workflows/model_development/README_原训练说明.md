# 逐元素筛选、双模型整地点训练与JIM外部验证

## 直接怎么运行

1. 先双击 `快速检查_约2至5分钟.bat`，确认环境和文件正常。
2. 快速检查成功后，双击 `开始正式训练_约1至2小时.bat`。
3. 正式结果在 `元素筛选_双模型_整地点与JIM结果` 文件夹。

正式训练默认时间预算110分钟。不同电脑速度不同，通常约1–2小时；程序会在完整折或完整轮次边界检查时间，可能略早或略晚结束。

## 本版与上一版的区别

- 只保留 MLP 64→32 和 ExtraTrees 两个模型。
- 完全取消随机颗粒80/20训练，正式评价只使用整地点划分。
- 先从17元素开始逐元素向后消融，再用筛选后的元素自动训练两个模型。
- 同时保留17元素基线，防止“删元素后看似简单、实际性能下降”。
- 预先锁定约20%的地点。这些地点不参与元素筛选，最后单独测试一次。
- MLP采用训练内整地点早停、组均衡重采样、L2正则化和多初始化平均，重点抑制过拟合。
- 自动生成图片，不再只输出CSV。
- 模型锁定后才读取JIM，JIM不参与筛选、训练或调参。

## JIM外部验证怎么放

当前包没有原JIM数据文件。把原来的JIM表复制到本文件夹，并将文件名改为以 `JIM` 开头，例如：

`JIM独立外部验证.xlsx`

程序支持CSV和XLSX，会自动寻找常见元素列名及 `ΔFMQ`。模板见 `JIM外部验证_模板.csv`。如果JIM表没有真实ΔFMQ，程序仍输出预测，但不能计算R²、MSE、RMSE。

如果JIM所有样品共用同一个真实ΔFMQ，R²没有统计意义，程序会输出为空；MSE和RMSE仍可计算。

## 数据与剔除规则

- 输入原始宽松筛选表：1266颗。
- 按既定证据整组剔除 Mt St Helens Yn 7颗。
- 整组剔除 southern African kimberlites 27颗。
- 最终入模：1232颗、36个标签组、25个地点。
- 程序会自动核验数量；数据被误改时会停止，不会静默训练。

缺失值、未检出值及非正浓度只在训练折内进行中位数插补，并添加缺失指示信息。测试地点和JIM的信息不会参与插补器或标准化器拟合。

## 元素筛选规则

每轮先根据训练地点内的ExtraTrees重要性和元素冗余程度确定优先试删候选，然后分别进行整地点交叉验证。只有同时满足以下条件才真正删除：

1. 两模型加权综合MSE至少改善0.002；
2. 主模型MLP的MSE最多只允许恶化0.003；
3. 不少于6个元素；
4. 最多删除8轮。

因此程序不会为了“元素越少越好”强行删除。若17元素仍最好，最终会保留17元素，这也是有效结论。

## 重点看哪些结果

- `先看这里_结果总结.md`
- `最终保留元素.txt`
- `逐元素消融路径.csv`
- `模型指标汇总.csv`
- `锁定地点独立测试指标.csv`
- `JIM独立外部验证指标.csv`（放入JIM后才生成）
- `图片` 文件夹

`模型指标汇总.csv`同时给出两种口径：

- `平均折MSE`：正式整地点各测试折MSE的平均值，可与上一轮0.413对比；
- `按组汇总R2/MSE/RMSE`：将多轮预测按标签组汇总后计算，用于真实值—预测值图。

不要把两种口径混写。

## 输出模型

- `MLP64x32_锁定模型.joblib`
- `ExtraTrees_锁定模型.joblib`

之后可用 `predict_with_locked_models.py` 预测新的JIM或GEOROC数据：

```bash
python predict_with_locked_models.py --input 新数据.xlsx --model-dir 元素筛选_双模型_整地点与JIM结果
```

## 科学表述边界

JIM可表述为“独立于训练数据的外部验证集”，前提是本次看到JIM结果后不再根据它反向调参。锁定地点测试与JIM外部验证都应如实保留，无论结果是否低于0.4。
