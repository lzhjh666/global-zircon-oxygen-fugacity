# 美济礁与Jack Hills外部验证代码包

本代码包只包含代码和验证数据，制作过程中没有运行训练、调参或验证程序。

## 一、先准备模型

打开`模型文件放这里`文件夹，把上一轮结果中的两个文件复制进去：

- `MLP64x32_锁定模型.joblib`
- `ExtraTrees_锁定模型.joblib`

程序会检查模型与当前scikit-learn版本是否一致。版本不一致时会直接停止，不会勉强生成可能不可信的结果。上一轮模型使用的版本为`scikit-learn 1.3.2`，不要在验证前升级环境。

## 二、推荐运行顺序

### 第一步：内部约束ExtraTrees

双击：

`01_先优化ExtraTrees_约10至30分钟.bat`

这一步只读取原训练数据，通过重复整地点交叉验证选择叶节点大小、树深和特征抽样比例。它不会打开美济礁或Jack Hills数据。

运行后将生成：

- `ExtraTrees正则化内部结果`文件夹；
- `模型文件放这里/ExtraTrees_正则化锁定模型.joblib`。

如果暂时只想验证上一轮两个原始模型，也可以跳过第一步。

### 第二步：运行外部验证

双击：

`02_再运行外部验证_约1至3分钟.bat`

程序不会训练或调参。它会：

1. 加载锁定模型；
2. 对美济礁和Jack Hills特征进行预测；
3. 在读取Jack Hills标签前先写出冻结预测和SHA256；
4. 解封标签并计算R²、MSE、RMSE、MAE和平均偏差；
5. 检查是否存在训练集重复成分、元素超范围及多变量应用域距离；
6. 生成逐颗CSV、组级CSV、结论说明和两张图片。

## 三、如何发回结果

运行完成后，把最新生成的：

`外部验证结果_美济礁_JackHills_日期时间`

整个文件夹压缩后发回来即可。不要只截一张图，逐颗CSV和冻结声明也需要保留。

## 四、结果解释

- 美济礁主要按4个岩样组计算指标，不能把34颗锆石当作34个独立地区。
- Jack Hills 25颗均来自一个地点，同样不能证明全球泛化。
- 当真实ΔFMQ范围很窄时，R²可能出现巨大负值，应同时查看MSE、RMSE、MAE和平均偏差。
- 外部结果只用于一次性检验。若根据它修改模型，则修改后的模型需要寻找新的外部数据重新验证。
