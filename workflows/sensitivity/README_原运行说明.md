# 最终论文数据与敏感性检验本地运行包

## 已经完成并冻结

`frozen/` 中的数据已经正式冻结为 `ZIRCON_FMQ_PAPER_V1`：

- 10,879条逐颗数据均有唯一 `GLOBAL_RECORD_ID`；
- 新增627条GEOROC记录已获得内容哈希型稳定ID；
- 10,879条均有 `SOURCE_ID`；
- 10,879条均有 `REFERENCE_ID` 和原始 `Reference`；
- 共55个来源单元、48篇文献；
- 年龄和两种冻结模型预测均无缺失；
- `05_冻结清单_SHA256.json` 保存冻结文件哈希。

不要编辑 `frozen/` 中的文件。后续分析只从冻结文件读取。

## 本地运行

建议使用64位Python 3.11，并在本目录打开终端：

```bash
python -m pip install -r requirements.txt
python 02_运行全部敏感性检验.py
```

程序不会训练、调参或覆盖模型。默认运行2,000次随机删除和2,000次Kohistan噪声模拟。可以调整次数：

```bash
python 02_运行全部敏感性检验.py --iterations 5000
```

结果自动保存到 `sensitivity_results/`，包括：

1. leave-one-source-out逐来源结果和包络；
2. 随机删除10%、20%、30%来源；
3. 50、100、150 Ma时间窗；
4. Kohistan 113颗真实外部残差及噪声模拟；
5. 每窗颗粒数、来源数、文献数、最大来源占比；
6. 完整14元素敏感性；
7. 7张补充图和自动汇总报告。

## 文件用途

- `01_冻结最终论文数据.py`：冻结过程的可复现代码；最终数据已经生成，不必再次运行。
- `02_运行全部敏感性检验.py`：需要你在本地运行的正式分析程序。
- `inputs/`：原始最终预测和Kohistan外部验证数据。
- `models/`：旧版正式冻结MLP和ExtraTrees模型。
- `frozen/`：论文最终冻结数据、逐颗溯源表、来源及文献注册表。

## 预计运行时间

2,000次模拟通常约需数分钟到十余分钟，取决于CPU。程序只做预测和统计，不使用GPU也不会重新训练。
