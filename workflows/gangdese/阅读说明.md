# 冈底斯四河流碎屑锆石：旧冻结模型本地预测包

## 运行

将整个文件夹解压，在已经安装依赖的 Python 环境中直接运行：

```bash
python 冈底斯_冻结模型预测.py
```

如缺依赖，先执行 `python -m pip install -r requirements.txt`。模型由 scikit-learn 1.3.2 保存；若运行环境版本不同，脚本会明确停下，避免兼容性错误。**脚本只执行旧模型的 transform/predict，不调用 fit、训练或调参。** 无命令行参数，不需要一键启动按钮。

## 输入和筛选

- `G47745_SuppData.xlsx`：Tang et al., *Geology* 49, 76–80 (2021), DOI 10.1130/G47745.1 的补充数据；River 1–4 为东冈底斯现代河沙的逐颗碎屑锆石。
- 14种模型元素中至少有12种实测且数值大于0；低于检出限的文本当作缺失；0–4000 Ma；P>750 ppm、La>1 ppm、Th/U<0.1 的记录排除（变量未测不据此排除）。全部筛选依据逐颗输出。
- `models/` 为过去选定的MLP与ExtraTrees正式冻结对象，不是新模型。

四个工作表原始共1,639颗；这里按代码筛选的候选数量预期约1,505颗。最终以脚本实际输出的逐颗筛选对账为准。

## 固定比较

结晶年龄40–65 Ma与10–25 Ma；每条河流先各自取中位数，只在同一条河流两个时期都有锆石时做配对阶段差。另画0–120 Ma五百万年窗口的四河流曲线，展示来源差异，不用孤立的年龄窗挑选峰谷。

外部地质对照是 Wang et al., *Economic Geology* 109 (2014) 所报告的东冈底斯磁铁矿—钛铁矿矿物对：较早期平均约−0.2 ΔFMQ（n=5），中新世约+1.8（n=6）；角闪石也显示后期升高。原文链接：https://pubs.geoscienceworld.org/segweb/economicgeology/article-abstract/109/7/1943/128655/

输出 `results/` 包含逐颗筛选和预测、各河流阶段中位数、同河流配对差值、汇总JSON和两幅图。验证重点为**变化方向**。矿物对参考值不是逐颗锆石的配对真值，不计算颗粒级RMSE。四河流是现代沉积汇，仍需关注其物源构成；这项区域案例单列，不追加进10,879条全球分析表。
