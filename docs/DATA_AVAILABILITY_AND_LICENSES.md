# Data and software licensing notes

## Software source code

No blanket open-source license is applied to the project code in this release. Public visibility on GitHub does not itself grant permission to reuse, modify, or redistribute the code. A project-wide software license should be added only after the project team and supervisor approve one.

## GEOROC-derived data

The 627-row GEOROC addition included in this repository is distributed under **Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)**, following GEOROC's stated terms. Users must credit GEOROC and the original data sources and distribute adaptations under the same license.

License: https://creativecommons.org/licenses/by-sa/4.0/

## Kohistan supplementary data

The Kohistan supplementary workbook retained in `workflows/kohistan_validation/数据来源/` is associated with Ahmad et al. (2026), an open-access article under **Creative Commons Attribution 4.0 International (CC BY 4.0)**. Cite the article and retain attribution.

License: https://creativecommons.org/licenses/by/4.0/

## Publisher materials not redistributed

The Wang et al. (2025) and Tang et al. (2021) GSA supplementary workbooks are not included. The full grain-level global compilation and grain-level outputs derived from the Wang et al. (2025) supplementary compilation are also not included. Obtain those materials from the publisher and follow the applicable terms.
